# Hyprland Dotfiles

## Stack
- OS: Arch Linux
- WM: Hyprland
- Bar: Waybar
- Terminal: Alacritty + Zsh + Oh-my-zsh
- Launcher: Rofi
- Notifications: Swaync
- Lock: Hyprlock
- Login: SDDM + astronaut theme
- Font: Hack Nerd Font
- Theme: Tokyo Night

## Manual installs
- Nekoray: https://github.com/MatsuriDayo/nekoray/releases
  Extract to ~/src/nekoray
